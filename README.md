## How to run

1. Download or extract the project.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a modern browser.
4. Click the cover to open the card.
5. Click **Play Music** to start the included audio.
6. Use the customization section to change the names, message, photo, or audio.

## GitHub submission

1. Create a new **public** repository on GitHub, for example:
   `teachers-day-message-card`
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
   - the complete `assets` folder
3. Commit the files.
4. Open the repository's **Settings → Pages** if you want a live webpage.
5. Choose the main branch and `/root` folder, then save.
6. Submit the repository URL and, if requested by your teacher, the GitHub Pages live URL.

## Important

The supplied music file is included in the project and converted to MP3 for better browser compatibility. The original M4A is also retained in `assets/`.

Make sure you have permission to redistribute any music or photo you upload to a public GitHub repository.
